# Evidence Camera
Installation — Android

1. Open the "GitHub Releases" (#) page.
2. Download the latest ".apk" file from the Assets section.
3. Once the download is complete, open the ".apk" file.
4. If Android asks for permission to install apps from this source, enable Allow from this source for your browser or file manager.
5. Return to the APK and tap Install.
6. Once installation is complete, open the app.

Updating the App

When a new version is released:

1. Download the latest APK from the GitHub Releases page.
2. Open the APK.
3. Tap Update/Install.

Your existing app data should remain available unless the app was uninstalled or the new release changes how data is stored.

Important

Only download the APK from the official GitHub Releases page. Android may display a security warning for apps installed outside Google Play. Make sure you trust the source before installing.
